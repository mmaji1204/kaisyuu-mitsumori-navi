# 相見積もりサイトとしての訴求を明確化

白・深緑・オレンジのデザインを維持し、トップを見た瞬間に不用品回収の相見積もりサイトと分かるように変更。

- メイン見出しを「不用品回収は、相見積もりで比較。納得できる業者へ。」に変更。
- サービス説明に「一度の入力」「複数業者の料金・日程・作業内容を比較」を明記。
- 右側の淡い緑のカードに2枚の見積書イメージを配置。実在業者や金額を示すものではなく、イメージと明記。
- 対応業者数が地域・回収内容によって異なることを表示。
- ヘッダー、地域入力、固定ボタン、フォームの文言を相見積もりに統一。
- 利用の流れ、FAQ、ページタイトル・説明文も相見積もりの案内に合わせて更新。

## 確認

- ESLint、本番ビルド成功。
- 幅1440px・390px・320pxで横方向のはみ出しなし。
- 390pxでメイン見出しとCTAを画面内で確認。
- CTAから地域入力へ進み、広島県・広島市中区をフォームへ引き継ぐことを確認。
- 地域入力後は名前欄にフォーカス。ブラウザエラーなし。
- 実際の見積もり送信は行っていない。
